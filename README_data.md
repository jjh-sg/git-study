# 버스 노선/하차 더미 데이터 생성기 v2

```
python make_dummy.py [--routes N] [--days N] [--start YYYY-MM-DD] [--seed N] [--out FILE]
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--routes` | 8 | 노선 수 (기본 8개 이후는 중복 없는 ID로 자동 생성) |
| `--days` | 7 | 생성 기간(일) |
| `--start` | 2026-09-01 | 시작일 |
| `--seed` | 42 | 난수 시드 (같은 값이면 같은 결과) |
| `--out` | 버스_노선_하차_더미데이터.xlsx | 출력 파일 |

## 스키마 (v1과 동일, 컬럼 추가 없음)
- 시트 `노선데이터`: 노선ID, 노선명, 노선유형, 정류소순번, 정류소ID, 정류소명, 기점, 종점, 누적거리(km), 첫차, 막차, 배차간격(분)
- 시트 `하차데이터`: 번호, 일자, 요일, 시간대, 노선ID, 노선명, 정류소순번, 정류소ID, 정류소명, 일반, 청소년, 어린이, 경로, 기타, 하차합계

## 현실성 보정
- 종점은 하차가 많고, 환승 거점(서울역, 종로3가, 강남역, 잠실역, 영등포, 신도림, 노원역, 공덕역)은 가중치가 높음
- 주말은 0.55배, 공휴일(2026-09-24~26 추석, 10-03 개천절, 10-05 대체공휴일, 10-09 한글날)은 0.4배
- 정류소ID는 전 노선 공통, 노선ID는 중복 없음, 누적거리는 순번에 따라 단조 증가

생성된 xlsx는 `.gitignore` 대상이다.
