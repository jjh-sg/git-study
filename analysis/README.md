# 하차 혼잡도 분석

## 방법
- 입력: `버스_노선_하차_더미데이터.xlsx` (하차데이터 시트, 2026-09-01~09-07, 8개 노선, 총 하차 165,524명) — 더미 데이터이며 git 제외 대상
- 실행: `python analysis/analyze_peak.py` -> `analysis/혼잡도_분석결과.xlsx`
- 시트: 시간대별_하차합계, 평일주말_비교(일평균, 평일 5일/주말 2일), 정류소_TOP10, 노선별_피크시간대, 혼잡도등급_전체/요약
- 혼잡도 등급: 정류소x시간대 하차합계 분위수 기준 — 상위 20% = 상(>=403), 상위 20~60% = 중(166~402), 나머지 = 하(<166)

## 핵심 인사이트
- 피크는 출근 08시(18,555명, 11.2%)와 퇴근 18시(17,552명, 10.6%), 다음 07시(13,138명)
- 평일 일평균이 주말의 약 1.8~2.0배이며 전 시간대에서 비슷한 배율; 주말도 08시·18시가 최대지만 낙폭이 작음
- 정류소 TOP10: 종로3가(21,299) > 잠실역(17,896) > 공덕역(10,937) > 신도림(8,358) > 삼성역(8,194) ... (환승거점 가중치 반영)
- 노선별 피크: 100번·143번·340번·472번·7016번은 08시, 271번·501번·9401번은 18시 (피크 집중도 11~13%)
- 혼잡도 '상' 셀은 114개(전체 570개 중 20%): 출퇴근 시간대의 주요 거점 정류소에 집중
