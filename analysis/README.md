# 하차 혼잡도 분석

## 방법
- 입력: `버스_노선_하차_더미데이터.xlsx` (하차데이터 시트, 2026-09-01~09-07, 8개 노선, 총 하차 110,361명) — 더미 데이터이며 git 제외 대상
- 실행: `python analysis/analyze_peak.py` -> `analysis/혼잡도_분석결과.xlsx`
- 시트: 시간대별_하차합계, 평일주말_비교(일평균, 평일 5일/주말 2일), 정류소_TOP10, 노선별_피크시간대, 혼잡도등급_전체/요약
- 혼잡도 등급: 정류소x시간대 하차합계 분위수 기준 — 상위 20% = 상(>=266), 상위 20~60% = 중(131~265), 나머지 = 하(<131)

## 핵심 인사이트
- 피크는 출근 08시(12,292명, 11.1%)와 퇴근 18시(11,505명, 10.4%), 다음 07시(9,234명)
- 평일 일평균이 주말의 약 1.8~2.1배이며 전 시간대에서 비슷한 배율; 주말도 08시·18시가 최대지만 낙폭이 작음
- 정류소 TOP10: 장위동(7,439) > 종로3가(6,296) > 삼성역(6,114) > 신촌(6,072) > 광화문(5,807) ...
- 노선별 피크: 100번만 18시, 나머지 7개 노선은 08시 (피크 집중도 10~12%)
- 혼잡도 '상' 셀은 115개(전체 570개 중 20%): 출퇴근 시간대의 주요 거점 정류소에 집중
